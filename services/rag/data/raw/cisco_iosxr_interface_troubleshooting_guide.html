1. Interface State Interpretation

An interface status consists of two parameters: physical link state and line protocol state. The operational state combinations are:

  • Up / Up: Fully operational. Forwarding packets normally.
  • Administratively Down / Down: The interface has been configured with the shutdown command. To restore, configure no shutdown.
  • Down / Down: Physical layer failure. Check cable, SFP transceiver, remote device power, or fiber patch.
  • Up / Down: Physical carrier detected but data link layer protocol failed. Typically caused by encapsulation mismatch, clocking issue, or keepalive failure.

2. Diagnosing Administrative Shutdown

When an operator or automated playbook executes an administrative shutdown:

RP/0/RP0/CPU0:spine1(config)# interface HundredGigE0/0/0/1
RP/0/RP0/CPU0:spine1(config-if)# shutdown
RP/0/RP0/CPU0:spine1(config-if)# commit

The router logs: %LINK-3-UPDOWN: Interface HundredGigE0/0/0/1, changed state to administratively down.

This event induces downstream BGP session tears on attached peer leaf routers within the detection window.

3. Optical Monitoring and Carrier Transitions

Inspect optical parameters with the command:

show controllers HundredGigE0/0/0/1 phy

Monitor carrier transition counters. A high carrier transition rate indicates link flapping caused by marginal optical power.
